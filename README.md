# AI Cinema & Timed Multi-Shot Pipeline

An open-source repository featuring modular multi-shot prompt architectures, timed cinematic execution structures, and Python helper utilities for generative AI filmmaking.

## 📌 Included Tools

1. **`cinematic_multishot_pipeline.md`**  
   Production-tested prompt framework for multi-shot scene generation, timecode-based hard cuts, spatial blocking, and lighting preservation.

2. **`acting_performance_engine.py`**  
   Python script for generating non-verbal character acting profiles, eye-saccade rules, and physical business descriptions.

## 🚀 Quickstart

```bash
# Clone the repository
git clone [https://github.com/arieshiggsfieldcreator-cell/pr7nal-ai-cinema-pipeline.git](https://github.com/arieshiggsfieldcreator-cell/pr7nal-ai-cinema-pipeline.git)

# Run the acting utility
